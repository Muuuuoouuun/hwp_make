HWP Make Basic 1.0.0

Windows 10/11 64비트용 기본 변환 앱입니다.
Python, 브라우저, 로그인, API 키를 따로 준비할 필요가 없습니다.

사용법
1. 파일 선택: PDF, HWP, HWPX, DOCX, TXT 또는 이미지 (최대 64MB)
2. HWPX 또는 DOCX 선택
3. 변환하고 저장: 저장할 위치와 이름 선택
4. 결과 열기 또는 저장 폴더에서 문서 확인

PDF → HWPX는 원본 전체 페이지 배치를 유지하는 변환을 사용합니다.
그 외 변환은 내용을 다시 구성하므로 원본 페이지 배치와 다를 수 있습니다.
스캔·이미지는 AI OCR 없이 이미지로 보존될 수 있습니다.
HWPX를 열고 편집하려면 해당 형식을 지원하는 한글이 필요합니다.
DOCX는 Word 등 해당 형식을 지원하는 프로그램에서 확인해 주세요.
원본 파일은 수정하지 않습니다. 수식·그림·인쇄 배치는 결과에서 확인해 주세요.

기본판에는 문항 편집·선택·재배열·자동 번호 설정·시험지 스튜디오,
구독·결제·AI 연결 설정이 없습니다. 별도의 서버나 인터넷 연결도 필요 없습니다.

앱 기록: %LOCALAPPDATA%\HWP Make Basic
변환 파일: 사용자가 저장 대화상자에서 선택한 위치
제거: Windows 설정 > 앱 > 설치된 앱 > HWP Make Basic > 제거
제거해도 저장한 문서와 최근 기록은 유지됩니다.

포함된 오픈소스 구성 요소의 라이선스는 _internal\licenses에 있습니다.
