# HWP Make 화면 시안 (2026-11-25)

게시본(비공개, 캔버스 v33): https://claude.ai/artifact/7mHyPD7QKf3PKoCYA4LArs

이 폴더는 위 캔버스의 원본이다. 각 `*.dc.html`이 화면 한 장(총 45장)이고, 공통 스타일은 `hm.css`, 캔버스 배치·크기·제목은 `canvas.json`에 있다. 앱 코드에는 아직 반영하지 않은 시안이다.

## 원칙

- 기본 화면에는 편집 도구를 두지 않고, 기본 다운로드를 결제로 가리지 않는다 (`docs/premium_studio_product_plan.md` 2장).
- 처음에는 로그인 없이 바로 무료로 변환한다. 흐름: 홈에서 바로 변환 → 완료 화면에 남은 무료 횟수와 가입 혜택 → 무료 횟수를 다 쓰면 무료 가입 안내 → 공개 회원가입 → 인증 메일.
- 가입은 무료이며 결제가 아니다. 결과 품질을 낮추지 않고, 이미 만든 결과의 다운로드는 막지 않는다. 유료로 막히는 것은 Premium(문항 편집·번호 맞춤)뿐이다.
- 요금은 정해지지 않아 적지 않았다. 내 시험지 목록, 결과 버전, 이용권 상태는 기획 문서를 기준으로 그린 계획 화면이다.
- 접근성: 본문 15px, 조작 요소 44px, 대비 AA.

## 정해야 할 값 (화면에 자리표시로 남김)

- 로그인 없이 쓸 수 있는 무료 횟수 `[N]`
- 가입하면 늘어나는 무료 횟수 `[M]`
- 무료 횟수가 다시 채워지는 주기
- 로그인하지 않은 결과의 보관 기간
- 인증 링크의 유효 기간
- 점검 화면의 "점검 전 접수 작업은 점검 뒤 확인 가능", "로컬 앱은 점검과 무관" 안내는 아직 시스템이 약속하지 않은 문구라 운영 방식에 맞춰야 한다.

## 현재 시스템에 없는 기능 (시안에서 새로 가정)

- 공개 회원가입과 이메일 인증 (현재 웹 프로토타입은 초대 링크로만 계정을 만든다)
- 인증 전에 만든 결과를 가입 후 내 작업으로 옮기기
- 로그인하지 않은 결과를 같은 브라우저에서만 다시 받기
- 홈 첫 화면의 회원가입 버튼과 무료 안내 한 줄 (기획의 "첫 화면은 로고·로그인·파일 입력만"에 더한 것)

## 검증

모든 화면을 1440(모바일은 390) 폭으로 headless Chrome에서 렌더해 가로 스크롤, 프레임 밖 요소, 겹침, 44px 미만 조작 요소, 대비 미달이 없음을 확인했다. 다크 모드에서도 밝은 화면을 유지한다. 실제 캔버스 렌더러와는 미세하게 다를 수 있다.

## 현재 구현과 달라진 제안

1. 파일 인식 후 기본(주 동작)과 Premium(보조)을 카드 두 개로 나눈다.
2. 변환 중에는 업로드→변환→점검→다운로드 단계를 보여 준다. 취소해도 서버 생성이 계속될 수 있다고 안내한다.
3. 완료 화면에서 확인 필요 문항을 맨 위로 올리고, 점검 점수에 "정확도 보증 아님"을 붙인다.
4. 조작 요소 32→44px, 본문 13→15px, 테두리 대비 #c7cfdf→#8a94a6.
5. 웹 프로토타입 녹색(#184e3b)과 로컬 앱 파랑(#2f56c7)을 하나로 합치고, Premium은 짙은 상단바와 배지로만 구분한다.
