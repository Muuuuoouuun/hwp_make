필요한 문항만 담고, 끌기·이동 버튼·위치 지정으로 순서를 정합니다.

자동 번호

순서대로 번호 매기기, 시작 번호(1~999), 원번호 유지 중에서 고릅니다.

정답·해설 번호 맞춤

입력에 있는 정답·해설을 새 번호로 옮깁니다. 정답 추론이나 해설 생성은 하지 않습니다.

초안 저장·복제예정

여러 시험지를 이름으로 저장하고 복제해 일부만 바꿉니다.

지원 범위

  • 지원편집 가능한 일반 문항 — HWP·HWPX·DOCX, 글자가 들어 있는 PDF
  • 지원정답·해설이 입력 자료에 있는 경우 새 번호에 맞춰 이동
  • 제한이미지 속 번호·스캔 문서는 자동 번호 변경 대상이 아닙니다
  • 제한공유 지문·이어지는 문항은 자동 번호를 지원하지 않습니다
  • 제한본문 속 다른 문항 번호 참조는 자동으로 바꾸지 않습니다
