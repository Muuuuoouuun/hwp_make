# UI 문항 이동·배치와 페이지 경계 평가

측정일: 2026-07-17

## 대상 흐름

`/` 접속 → 길이가 다른 문항을 시험지에 담기 → 위/아래 버튼과 드래그로 순서 변경 → 예상 페이지·단 갱신 → HWPX 내보내기

브라우저 플러그인은 현재 세션에 없어 Playwright CLI를 사용했다. 테스트 서버는 별도 임시 데이터 디렉터리로 실행해 실제 문제은행을 변경하지 않았다.

## 발견한 문제

| 상황 | 기존 동작 | 위험 |
| --- | --- | --- |
| 문항 높이 차이 | 홀수 문항은 왼쪽, 짝수 문항은 오른쪽으로 고정 표시 | 긴 문항도 `2행·오른쪽`처럼 표시되어 실제 단·페이지와 불일치 |
| 양식 변경 | 기본 1단 양식에서도 UI는 항상 `2단 시험지`로 표시 | 사용자가 잘못된 배치를 기준으로 순서 결정 |
| 긴 문단 | writer가 자동 줄바꿈된 한 줄을 한 문단 높이로만 계산 | 단 하단 잘림 또는 다음 문항과 겹침 가능 |
| 경계 직전 문항 | 수학 네이티브 수식 경로 외에는 문항 전체 높이 사전 확인이 없음 | 한 단에 들어가는 문항도 중간에서 분리될 수 있음 |
| 긴 표·세로 이미지 | 단 하나보다 큰 객체를 그대로 배치 | 페이지 하단 잘림 가능 |

## 개선 내용

### UI

- 선택한 양식의 실제 `columns` 값에 따라 1단/2단을 표시한다.
- 본문 줄 수, 줄바꿈 폭, 선지, 표, 이미지, 정답·해설을 합산해 문항 높이를 추정한다.
- 문항별 예상 쪽·단·높이 비율을 표시한다.
- 한 단보다 긴 문항은 `분할 예상`, 단 높이에 가까운 문항은 `경계 주의`로 표시한다.
- 여러 단에 걸친 문항은 다음 단에 `이어짐` 영역을 표시한다.
- 순서 버튼 또는 드래그 후 전체 페이지·단 배치를 즉시 다시 계산한다.
- 모바일에서는 두 단을 세로로 접어 가로 잘림 없이 표시한다.

### HWPX writer

- 2단 문서의 일반 문단도 출력 폭에 맞춰 명시적으로 줄바꿈하고 실제 줄 수만큼 높이를 예약한다.
- 한 단에 들어갈 수 있는 문항은 남은 공간이 부족하면 문항 시작 전에 다음 단으로 이동한다.
- 단보다 큰 문항은 문단 단위로 안전하게 이어 간다.
- 긴 표는 행 단위로 나누고 다음 조각에 머리행을 반복한다.
- 세로 이미지는 단 본문 높이 안으로 축소한다.

## 시뮬레이션 결과

스트레스 fixture는 짧은 문항, 9줄 문항, 34줄 문항, 29행 표, 긴 5지선다를 섞었다.

| 검사 | 결과 |
| --- | --- |
| 정방향 HWPX | 7쪽, 명시적 단 이동 12개, overflow 0, 단 침범 0 |
| 역방향 HWPX | 6쪽, 명시적 단 이동 11개, overflow 0, 단 침범 0 |
| 표 분할 | 머리행 반복 확인 |
| 출력 순서 | 정방향·역방향 모두 요청 순서와 일치 |
| UI 위/아래 버튼 | 긴 문항 이동 후 번호·예상 단·이어짐 구간 갱신 |
| UI 드래그 | 긴 문항을 첫 위치로 이동, 첫 카드와 후속 페이지가 즉시 갱신 |
| UI 실제 내보내기 | 8문항 완료, 긴 문항이 출력 첫 순서로 유지 |
| UI 출력 렌더 | 실제 2쪽, overflow 0, 단 침범 0 |
| 브라우저 콘솔 | 오류 0, 경고 0 |
| 반응형 | 1440×1000, 390×844 통과 |
| 통합 회귀 | 22 PASS, 1 SKIP, 0 FAIL |

UI의 페이지 수는 안전 여유를 둔 예상치다. 실제 UI fixture에서는 3쪽으로 예상하고 HWPX는 2쪽으로 렌더됐다. 잘림을 놓치지 않는 방향의 차이이며 확정 페이지 수로 사용하지 않는다.

## 남은 위험

1. UI 추정기는 한컴의 실제 폰트 대체와 줄바꿈 엔진을 실행하지 않으므로 페이지 수가 정확히 일치하지 않을 수 있다.
2. rhwp 미리보기는 아직 다단을 1단으로 렌더하므로 최종 2단 모양의 브라우저 미리보기는 제한적이다.
3. 마우스 드래그와 이동 버튼은 검증했지만 모바일 터치 드래그는 별도 구현하지 않았다. 모바일에서는 이동 버튼을 사용해야 한다.
4. Chrome 계열 Playwright에서 검증했으며 Firefox, WebKit, 여러 한컴 버전은 추가 표본이 필요하다.
