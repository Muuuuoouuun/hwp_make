# 2026-10-09 작업 저장 요약

현재 저장 대상은 제품에 반영한 기본 변환·공개 편집 수정과 그 검증 문서다. 후속 TMP 후보는 제품 적용본과 구분한다. 최신 제품 기준은 **app199 / Windows native5**이며, 전체 품질 완료나 Mac 지원 완료를 뜻하지 않는다.

## 제품에 반영한 내용

- 원본 문항 소속·글꼴·현재 폭을 확인한 선택지 열 제목의 수평 배치와, 문자가 들어간 답란의 편집 가능한 TAB·밑줄 생성을 연결했다. 빈 답란은 현재 보이는 선·덮개·glyph 윤곽을 검사해 가려진 옛 선의 잘못된 복원을 막는다. [열 제목](source-choice-column-headers-20261008.md), [문자 답란](source-labeled-answer-rules-20261008.md), [현재 답란 판정](source-current-answer-rule-paint-20261009.md).
- 공개 run/문단에 같은 값을 다시 넣으면 노드·서식·TAB·줄 cache를 유지한다. 새 리터럴 TAB은 명시적 LEFT/type 1·leader 0으로 만들고, 실제 폭 측정의 지원 TAB 수를 8→16으로 늘렸다. 기존 스타일·UTF16·폭·연산 예산과 보수적 복귀 조건은 유지한다. [공개 TAB 기록](native-public-tab-controls-20261009.md).
- 일반 문항의 수동 나눔과 자동 생성 나눔을 구분하는 이력, 유효한 간격·leading 보존을 연결했다. 실제 고3 대상의 긴 편집과 재열기 후 원문 복귀는 8→9→8쪽이며 baseline 8개 SVG와 같다. 과거 행·좌표·높이를 그대로 재생하는 방식은 아니다. [일반 페이지 복귀](general-break-history-20261009.md), [간격 보존](native-gap-edit-20261009.md).
- 원본 전체 frame이 확인된 편지의 맺음말·이름·직책을 실제 행별 문단으로 유지하고, 자격이 맞는 마지막 서명 행의 현재 문단 서식을 복제해 편집 후 불필요한 간격 증가를 막았다. [편지 제품 기록](letter-closing-rows-20261009.md).
- 기존 공통 지문 소속·내보내기, 출력 번호 중복 방지와 스튜디오 미리보기 연결 보강도 함께 보존한다. 이는 기존 기능의 수정 저장이며, 프리미엄 자유 재정렬·새 양식 개발을 완료했다는 뜻은 아니다. [기존 편집·번호 계약](../../premium_studio_implementation.md).

영어3종의 원문/native 텍스트 보존 1.0과 기본 열기·편집 구조·렌더 검사는 통과했다. 이 집계가 모든 글자의 실제 표시나 의미 밑줄의 보존을 보증하지는 않는다. 공개 편집의 같은 값 대입·보유 노드·TAB·문단 회귀와 일반 간격 복귀, 편지 서명 반복 편집도 각각 검사한 범위에서 통과했다. 반복 소속 검사를 독립 사용자 시나리오 수로 합산하지 않는다. [최신 통합 판정과 근거](question-priority-bottlenecks-20261008.md).

이번 저장 전 별도 검증도 통과했다. [번호·공통 지문 검사](../../../scripts/verify_premium_numbering.py)는 단독·역순 지문과 원래 번호 1회 표기, 양쪽 writer와 기본 변환 우회 계약을 확인했고, [스튜디오 검사](../../../scripts/verify_studio_views.js)는 번호·화면 계약을 통과했다. [영어 내용 무결성](../../../scripts/verify_english_content_integrity.py)은 합성 입력 83검사·실제 HWPX/DOCX 내보내기 12건에서 실패 0건이었다. 변경 Python 117파일의 구문 검사와 배포 파일·wheel RECORD 검사도 통과했다. 이 검사는 새로운 전체51종 실행이나 프리미엄 자유 재정렬 완성의 증거가 아니다.

## 후속 TMP 후보 — 제품 미적용

- 표 흐름·baseline 정수 보존을 합친 v6는 실제 영어3종, 22셀 잉크·공개 저장·재열기·현재 상태 변조 거절·rollback과 기존 회귀를 검사했다. 큰 표 성장과 일반→수정된 격자→일반의 혼합 복귀는 미완료이며 제품에 복사하지 않았다.
- 고1 공통 지문의 초기 글자 잘림 복원과 source 단어 밑줄 복원 후보는 별도다. 기존 글자의 X 불변 gate에서 실제 이동을 발견해 원본으로 복귀했다. native 구간별 폭 반올림 수정 후보의 첫 격리 빌드도 입력 파일 누락으로 중단했으며 새 renderer를 설치하지 않았다.
- 고3 선택지의 실제 9행·전각 대시 후보는 source/font/윤곽 및 보존 PDF의 대시 검증을 진행했지만 공개 성장·재열기·원문 복귀는 아직 미도달이다. 별도 offset renderer의 통제 입력 통과를 문항 전체·직접 Skia·회전 재열기 자격으로 확대하지 않는다.
- 일반 본문 폭 탐침을 한 페이지에 묶은 후보는 현재 단락과 스타일 경계의 세 폭 벡터가 기존 방식과 정확히 같았다. SVG 호출은 55→7회였지만 속도 개선은 확인되지 않았고, 전체 공개 성장의 1초 예산·최종 잉크·저장·복귀 검사는 실행하지 않았다.

## 남은 우선 병목

1. 고1 43–45번 공통 지문의 줄 끝 4글자 실제 잘림과 대명사 밑줄 다섯 곳 누락. 글자 수·원문 보존 집계와 실제 잉크/의미 표시를 함께 확인해야 한다.
2. 고3 선택지 내부 fragment 간격·전각 대시·혼합 글자 높이와 공개 편집 지속성. 선택지 시작 표지만 맞는 것을 전체 내부 정렬 완료로 보지 않는다.
3. 공유 지문 frame은 원문 복귀 뒤에도 행·표 높이·쪽수가 남는 문제가 있다. 최초 공개 성장의 실제 첫 실패는 native 누적 1초 예산 소진이며, 마지막 수동 flags 오류는 기본 fallback 뒤의 후속 오류였다.
4. 표·편지의 원본 Y/높이, 별도 어휘 주석의 1HWP baseline 차이, 답란 선의 원본 Y·두께와 편집 후 셀 높이가 남는다. 전체 과목의 다른 strict 이슈와 실제 한글 편집기 검증도 완료하지 않았다.

## Mac 전달과 현재 작업 상태

app199·실제 영어PDF3종·참고 HWPX를 담은 진단 v2 묶음이 준비돼 있다. 실제 Mac에서 압축을 푼 `hwp-make-mac-diagnostic` 폴더에서 다음 명령을 실행한다.

```sh
sh run_mac.sh --english3 --public-edit
```

**실제 Mac 설치·변환·공개 편집·재열기·렌더 결과는 아직 없다.** Windows 실측, 플랫폼 모의 fallback, ZIP 정적 검사를 Mac 성공 근거로 쓰지 않는다. 사용자가 지원 대상 Mac에서 실행한 `reports/run-…/bundle-result.json`과 같은 폴더의 로그를 제공하면 남은 호스트 차이를 판정할 수 있다. Windows 후속 구현에는 추가 외부 자료가 필요하지 않다. [Mac 실행 안내와 한계](macos-readiness.md).

목표 상태는 **PAUSED**다. 기존 진행 작업은 종료했고, 미적용 후보의 후속 빌드·공개 편집·실제 시험지 API 검증은 재개하지 않았다. 이번 요청을 위한 저장 전 회귀 검사만 별도로 실행했으며, 내용 정리와 기존 작업 저장을 제품 개발 목표의 재개로 해석하지 않는다.
