The shared `hwpx_writer_v2.py` source-layout/native/KICE-English gate calls it

positions only; source Y and labeled answer rules remain separate work.

Producer source items discover numbered owners. Candidate permission then
requires exact actual PDF raw glyph membership from the unique numbered
instruction through every physical fragment of the final choice row. A shortened
source/native pair cannot prove completeness by retaining only real source
glyphs. Each candidate also proves actual regular Times raw/trace/visible paint,
the embedded TTF/CID/GID/Unicode mapping, all seven current native font slots,
plain styles, actual source-column replay, canonical current wrapper widths and
all nine original cache attributes. Actual native paint binds every question
segment within its current page/column/wrapper band. The header receives three
editable native LEFT TABs using the installed default metric budgets.

The entire package is staged as parsed clones. Missing source, unsupported
content/style/cache, malformed ZIP/XML or a failed probe returns exact original
bytes. The file wrapper validates editor-open safety, checks that the target has
not changed during proof, and atomically replaces it only after success.
