# 기능 평가 및 개선 — 2026-09-21

후속 재평가: [문단·문항·그림·원본 배치 엄격 평가](strict-paragraph-assessment.md). 아래 수치는 이 문서 작성 시점의 기록이며, 현재 판정은 후속 평가를 따른다.

판정: **편집·문제은행 기능은 내부 베타 사용 가능. PDF 원본 복원은 출시 관문 미달.**
과거 UI 점수 97.6점을 현재 변환 제품 전체의 완성도로 사용하지 않는다.
이번 평가는 현재 작업 트리의 코드·자동 회귀·로컬 실물 PDF에 근거한다. 실제 브라우저 조작, 한컴 GUI 편집·재저장, 배포 검증은 포함하지 않았다.

## 이번에 반영한 변경

1. **표 경계 그림 보존:** 그림의 중심점만으로 표 내부라고 판단하던 오류를 수정했다. 그림 면적의 90% 이상이 표에 속할 때만 셀 배치를 시도하며, 그 외에는 원본 그림 전체를 독립 항목으로 보존한다. 표 내부의 불명확한 셀 배치는 계속 거부한다. 기존 셀 그림 2개와 표 경계 그림 1개의 실제 HWPX·렌더·원본 이미지 대조를 회귀로 고정했다.
2. **업로드 실제 수신량 제한:** Content-Length 누락·축소·잘못된 값으로 크기 제한을 우회하지 못하도록 JSON 파싱 전에 ASGI 본문 조각의 바이트를 합산한다. 제한 초과 시 413으로 종료하며 엔드포인트를 실행하지 않는다. 정상 청크·정확한 제한값·빈 본문·연결 해제도 검사한다.
3. **검증 결과의 정확성:** argparse 종료 코드 2를 SKIP으로 숨기지 않는다. 수동 자료가 필요한 CLI 5개는 실행 조건을 명시한 SKIP으로 구분한다. 웹 프로토타입은 pytest로 실행해 14개 테스트가 실제 수행된다. 수학 AI 샘플 부재도 PASS 대신 SKIP이다.
4. **실패 추적:** 전체 stdout/stderr, 실행 시간, 항목별 상태를 저장하고 각 검사 종료 후 JSON을 갱신한다. `--only`로 실패 항목만 재현할 수 있다. 타임아웃도 그때까지 출력된 내용을 남긴다.
5. **현행 네이티브 기준 적용:** 실물 PDF 검사에서 폐기된 수식 이미지 overlay 필수 조건을 제거하고 overlay 금지·네이티브 수식·독립 원문/편집성 대조를 검사한다. 원본 배치 임계값은 낮추지 않았다. 이미 지원하는 선분 분모 복원은 정확한 수식으로 검사하고, 근거 없는 숫자 밴드 복원은 계속 거부하는 회귀를 추가했다.

## 기능별 평가

전체 회귀 **76개 대상: PASS 64 · SKIP 11 · FAIL 1**. 실패는 실물 PDF 상세 품질 관문이다. 11개 SKIP은 수동 산출물·외부/개인 샘플 부재이며 통과로 계산하지 않는다. 웹 pytest 14개는 위 집계에서 한 스크립트로 센다. 마지막 수신 버퍼 보완 뒤 API/본문 제한 2개를 재실행해 모두 통과했고, 현행 네이티브 기준으로 갱신한 실물 관문도 별도 재실행해 실패 원인을 확인했다. 변경 Python 파일의 Ruff 검사와 diff 공백 검사도 통과했다.

| 기능 | 판정 | 근거와 제한 |

## 실물 PDF 수치

`2026_june_high1`의 국어·수학·영어를 structured native 경로로 변환했다.
첫 전체 재검사에서는 36쪽을 모두 비교했고 아래 수치를 얻었다.

| 과목 | 원본→출력 쪽수 | writer 시간 | 엄격한 시각 배치 평균 | 최저 페이지 |
| --- | --- | --- | --- | --- |
| 국어 | 16→16 | 10.531초 | 52.94 | 27.70 |
| 수학 | 12→12 | 3.019초 | 34.85 | 28.05 |
| 영어 | 8→8 | 7.008초 | 52.01 | 43.22 |

점수는 `overall_harsh_layout_score` / `minimum_harsh_layout_score`이며, 이 검사의 평균 목표는 97·최저 목표는 95다. 업로드·검수·다운로드 시간은 writer 시간에 포함하지 않았다. 다른 검증과 함께 실행한 1회 측정이므로 성능 우열 비교에 사용하지 않는다. writer 자체 텍스트 포함률 100%도 독립 원문 대조의 통과나 의미 정확도를 보장하지 않는다.

현행 독립 편집성 검사까지 연결한 후속 실행에서는 **3부 모두 실패**했다. 이는 writer가 파일을 생성한 것과 사용자에게 제공 가능한 변환 성공이 다름을 뜻한다. 공개 API는 이 관문 실패 시 422로 거부한다.

| 입력 | 독립 검사에서 확인된 출시 차단 항목 |
| --- | --- |
| 국어 45문항 | 한 상자 내 문항 수·번호 불일치, 문항 내용의 상자 밖 배치, 원본 그림 누락 판정 |
| 수학 30문항 | 문항 내용의 상자 밖 배치, 원문 의미 불일치 판정 |
| 영어 45문항 | 문항 내용의 상자 밖 배치, 원본 그림 누락 판정 |

세 과목 모두 `text_in_drawing_boxes`도 보고했다. 누락 판정의 세부 원인과 지원 범위는 문항별로 추가 분석해야 하며, 이 결과를 무시하거나 검사 임계값을 낮춰 통과 처리하지 않았다.

```powershell
pip install -r requirements.web.txt pytest
python scripts/run_all_verify.py --output-dir data/verification/20260921_final
python scripts/run_all_verify.py --only verify_external_exam_detail_quality.py verify_regression_runner.py --output-dir data/verification/20260921_native_gate
```
