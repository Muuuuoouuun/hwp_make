# PDF → 편집 가능한 한글: 여백·표 번호·머리말 개선

2026-09-21. [문단·편집성 엄격 평가](strict-paragraph-assessment.md)의 후속 개발 기록이다. 요청한 5개 분야를 **품질·정확도·편집성·안정성·성능**으로 나눠 확인했다. 품질·정확도 실패가 남으면 다른 항목의 통과 개수로 상쇄하지 않는다. **93점 달성 및 완성본 판정은 아직 실패다.**

## 실제로 바꾼 동작

- 원본의 좌우 단 시작 위치를 한글의 실제 쪽 여백·단 간격에 반영한다. 문항 사이 풀이 여백은 문단 앞 간격으로 저장한다. 첫 장과 뒤쪽 본문의 위 여백 차이는 실제 구역으로 구분한다.
- 단 전환용 빈 문단이 왼쪽 단에만 한 줄을 추가하던 오류와, 문항 상자에 이미 포함된 여유 높이를 밖에서 다시 더하던 오류를 고쳤다. 3쪽 재현 문서에서 좌우 문항 시작점과 뒤쪽 두 쪽의 원본 문항 간격을 0.1픽셀 이내로 확인했다. 이 수치를 모든 실물 문서의 배치 오차로 확대하지 않는다.
- 그림 안에 이미 그려진 단독 원문자 번호를 별도 본문/표로 중복 생성하지 않는다. 번호 뒤에 문장이 붙는 실제 선지까지 제거하는 방식은 사용하지 않는다.
- 표 왼쪽의 ①~⑤를 표 아래 다섯 문단으로 늘어놓던 오류를 고쳤다. 원본 행과 연결되는 테두리 없는 실제 셀로 저장한다. PDF 글자 좌표로 따로 읽은 기대 행렬과 결과 표를 대조하며, 번호 삭제·행 교환·다른 셀로 이동시킨 변조는 실패한다.
- PDF에서 복원한 듣기 안내에 시험지 템플릿의 안내를 다시 덧붙이지 않는다. 교시는 원본에서 측정하고 템플릿의 임의 형식 표기를 섞지 않는다.
- 뒤쪽 모든 페이지에서 같은 영역명이 확인되면 실제 구역 머리말로 반복한다. 페이지 번호와 영역명이 같은 PDF 줄에 있는 경우에도 영역명 자체의 글자와 경계를 추출한다. 머리말 높이를 배정해도 본문의 시작 위치와 편집 후 가용 높이는 유지한다. 학년·쪽 번호·머리말 구분선까지 복원한 것은 아니다.
- 구역 전환을 문단의 `pageBreak`와 별도로 집계한다. 실제 구역 수와 실제 페이지 나누기를 더해 원본 경계를 검사한다. 원본의 48pt 여백과 일반 템플릿 20mm 여백이 다르면 템플릿 불일치를 그대로 기록한다. 배치 품질 점수의 임계값이나 시각 점수에 의한 총점 상한은 바꾸지 않았다.

## 검사 자료와 범위

최종 수치는 `data/verification/20260921_goal_native_final_v2/report.json`에 있다. 실행 시작 때 Python 코드를 메모리에 고정했으며 `tested_python_sources.zip`과 `source_hashes.json`을 함께 보관한다. 과목별 원본/출력 해시, 편집 전·후 HWPX, 36쪽 비교 PNG를 포함한다. 여기의 한글 파일은 **검수용 산출물**이다.

완료 시점 Python 소스 해시 차이는 0건이며 `source_differences_at_completion.json`에 기록했다. 실행기는 `tmp/strict_goal_eval_v2.py`, 동일 사본은 소스 ZIP의 `evaluate_snapshot.py`다. 이전 결과를 덮어쓰지 않고 별도 경로에 보존했다.

- 전체 회귀: `data/verification/20260921_goal_native_full/report.json`. 반복 영역명 머리말 추가 전의 전체 코드 기준이다.
- 머리말 추가 후 관련 회귀: `data/verification/20260921_native_heading_recheck/report.json` (7 PASS). 이후 동일 줄의 페이지 번호/영역명 분리 재현도 `verify_native_running_heading.py`에서 통과했다.
- 새 회귀: `verify_native_source_spacing.py`, `verify_native_table_gutters.py`, `verify_native_running_heading.py`.
- 한컴 COM은 설치·생성을 확인했지만 파일 열기가 파일 접근 모듈 등록 실패와 함께 응답하지 않았다. 이 실행은 미검증으로 남겼다. 직접 한컴 편집·저장 호환성은 완료 판정에 별도로 필요하다.

## 계속 해결할 실패

1. 국어 내부 배경 틀이 큰 보기 상자 안에 들어간 경우의 보존과 원본 안내 문장 연결을 고친다. 11건의 누락은 PDF 내부 이미지 조각 기준이며 서로 다른 그림 11개라는 뜻이 아니다.
2. HWPX 배경 리소스가 존재해도 실제 렌더에 보이지 않으면 실패로 유지한다. 국어·영어 배경 표시 누락을 해결하고, 국어의 10개 렌더 문장 미일치를 없앤다.
3. 문항 내부 글꼴·줄 높이·수식·선지 간격, 첫 장 제목 배치, 전체 반복 머리말/쪽 번호를 원본과 맞춘다. 설치 글꼴 이름으로 단순 치환한 실험은 수학 점수를 낮춰 적용하지 않았다.
4. 실제 한컴에서 열기·문단 수정·다시 저장·렌더를 확인하고, 확장 과목에도 같은 검사를 적용한다. 이 보고서는 국어·수학·영어 36쪽의 재평가이며 기존 21과목 전체의 재검증을 대신하지 않는다.

본문이나 수식을 이미지로 덮어 원본처럼 보이게 만드는 출력, 별도의 편집용 파일만 제공하는 방식, 합격선 완화는 완료 방법으로 사용하지 않는다.
