# PDF → 편집 가능한 한글: 문단 서식과 선택지 간격 재평가

2026-09-21. [직전 그림 주변 문단 평가](native-floating-paragraph-progress.md)와 같은 국어·수학·영어 36쪽을 다시 변환했다. **엄격 배치 평균은 68.64 → 69.09이며 목표 93점에 미달한다.** 수학 최저 페이지는 46.82 → 45.27로 악화했다. 전체 회귀는 **85 PASS / 11 SKIP / 2 FAIL**이다. 이 결과물을 완성본으로 판정하지 않는다.

## 변경과 검증

**문단의 들여쓰기를 실제 한글 문단 속성에 저장했다.** 이전에는 원본 줄의 위치 정보에만 일부 들여쓰기가 남아 있어, 편집 후 줄을 다시 계산하면 위치가 사라졌다. 이제 원본 전체 문장과 줄 경계가 일치하는 일반 본문의 첫 줄 들여쓰기·내어쓰기·왼쪽 여백을 `paraPr`에 저장한다. 문항 글상자의 바깥 문단과 안쪽 문단에 두 번 적용되지 않도록 글상자 구성 뒤에 적용한다. 표 셀, 중앙/오른쪽 정렬, 대응을 입증하지 못한 혼합 수식 문단은 이번 복원 범위에서 제외한다.

**공통 지문도 편집 후 실제 단 너비로 다시 조판한다.** 줄 캐시를 지운 공통 지문이 두 단을 가로질러 표시되는 오류를 실제 PDF 변환·편집으로 재현했다. 기존 갱신 경로는 문항 글상자와 그림이 붙은 문단에 한정되어 있었다. 이를 해당 문서의 일반 지문으로 확장했고, 단 전환과 문단 여백을 반영한다. 병합 셀을 처리하면서 페이지 여백 변수를 덮어쓰던 오류도 수정했다. 문단 수를 늘리거나 강제 줄바꿈을 넣어 해결하지 않았다.

**한 줄에 나란한 선택지에는 원본에서 잰 탭 위치를 넣었다.** 본문과 수식을 그대로 두고 한글 탭 속성과 원본 간격 캐시를 기록한다. 원본 선택지 기호·순서·좌표를 확인할 수 있는 행만 적용한다. 실물 적용은 국어 1행/4탭, 수학 22행/83탭, 영어 21행/32탭이다. 편집 후에는 탭 위치와 현재 글 길이로 간격과 줄 캐시를 갱신한다. 저장 검증기와 문단 오프셋 검사도 UTF-16 및 8단위 탭 제어 문자를 올바르게 센다. 잘못된 줄 시작 위치를 넣은 파일은 계속 거부한다. 단위 계산의 참고 근거는 [rhwp의 HWPX 파서](https://github.com/edwardkim/rhwp/blob/v0.7.13/src/parser/hwpx/section.rs)다.

**선택지 위치 검증은 실패 상태다.** 실제 바탕 글꼴 PDF를 사용하는 새 회귀에서 문단 유지·탭 속성·장문 편집·단 안 표시·재저장은 통과했다. 하지만 표시 위치의 최대 오차는 **7.89px**로 **6px** 기준을 넘었다. 글꼴 및 공백의 원본 폭과 렌더 폭 차이가 탭 간격에 누적되는 현상을 확인했다. 기준을 올리거나 실패를 생략 처리하지 않았다. 네이티브 탭 기능이 있다는 이유로 원본 위치까지 정확하다고 판정하지 않는다.

실물 국어 일반 지문의 검사는 문항 밖에서 처음 발견한 80자 초과·첫 줄 들여쓰기·순수 텍스트 문단을 대상으로 했다. 원래 96자에 126자를 더한 뒤에도 같은 문단과 같은 스타일을 유지했다. 실제 첫 줄 x=99.773px, 다음 줄 x=90.387px로 **704 HWPUNIT(9.387px)** 들여쓰기가 유지된다. 모든 추가 문장이 실제 SVG의 표시·클립 검사와 페이지/단 범위 검사를 통과했고, 4쪽 PNG도 확인했다. 결과는 17쪽으로 늘었다. 원래 쪽수에 맞추려고 글을 자르지 않았다. 그림 바이트·헤더 및 두 번째 저장의 섹션 XML도 유지된다. 이 표본을 모든 지문의 편집 호환성으로 일반화하지 않는다.
