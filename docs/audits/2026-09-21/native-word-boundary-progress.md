# PDF → 편집 가능한 한글: 그림 중복과 문단 띄어쓰기 재평가

2026-09-21. [배경 보존·병합 셀 편집 개선](native-background-reflow-progress.md) 이후 같은 국어·수학·영어 36쪽을 다시 변환했다. **엄격 배치 평균 67.65로 93점 미달이다.** 실제 한컴 GUI의 열기·편집·재저장도 아직 검증하지 못했다.

## 이번에 수정한 오류

**문단의 단어 경계.** 이전 출력은 줄을 합칠 때 항상 공백을 넣어 `극히→극 히`, `완화→완 화`처럼 원문 단어를 갈랐다. 기존 공백 제거 문자 대조와 문단 소속 검사만으로는 발견하지 못하던 문제다. 이제 PDF가 같은 글꼴의 긴 한글 줄 끝 공백을 반복해서 보존한 경우, 원본 스팬의 공백 유무를 따라 문단을 결합한다. 공백 증거가 없는 입력과 영어 줄에서는 단어 경계를 추측해 붙이지 않는다.

검증기도 생성기의 결합 결과를 기대값으로 쓰지 않고 PDF 원본 스팬과 실제 HWPX 문단을 대조한다. 국어에서 확정 검사한 **330개 줄 경계의 오류가 152개에서 0개**로 줄었다. 공백을 넣거나 지운 변조는 각각 실패한다. 본문과 보기 상자 안 문단 모두 재현 검사했다. 초기 탐색의 318개 중 144개 수치는 더 좁은 임시 추출 범위였고, 최종 판정은 330개 중 152개를 기준으로 한다. 문단 검사 실패는 기존 공개 API의 편집성 거부 조건에 그대로 포함된다.

**그림 라벨 중복.** 국어 5쪽의 원본 그림에 들어 있는 ‘액체·고체·접촉각’ 등을 다시 본문으로 생성해 문장에 끼워 넣고 별도 표로 만들던 오류를 수정했다. 실제 보존 그림 안에 완전히 들어 있고, 본문보다 작으며 길이·형태가 제한된 라벨만 중복 생성에서 제외한다. 원래 그림의 픽셀과 출처는 계속 검증한다. 그림 밖 글자·본문 크기 글자·문항/선지 시작·문장 끝 구두점이 있는 줄은 이 제외 규칙을 적용하지 않는다. 그림의 사각 테두리를 내용 없는 보기 상자로 다시 만들지 않는다. 그림 내부 라벨은 기존 그림에 보존되며 별도 편집 가능한 글자로 바꾼 것은 아니다.

**그림 옆 문단.** 그림 윗변이 첫 줄과 둘째 줄 사이에 있을 때 첫 줄만 별도 문단이 되던 오류를 수정했다. 원본에서 그림 옆에 놓인 연속 본문은 같은 실제 문단 안에 유지한다. 한 문항은 하나의 글상자에 문단·표·수식·그림을 담는 기존 구조를 유지한다.

앞선 배경 표시·원본 이미지 누락·표 오른쪽 번호·병합 셀 재조판·수식 연산자 폭 수정도 포함해 재검증했다. 본문 이미지 덮개나 별도 편집용 파일을 도입하지 않았고, 배치 산식·합격선도 바꾸지 않았다.
