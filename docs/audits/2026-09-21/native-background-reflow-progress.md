# PDF → 편집 가능한 한글: 배경 보존·병합 셀 편집 개선

2026-09-21. [앞선 개발·5분야 평가](native-development-progress.md)의 후속 기록이다. **93점과 완성본 판정은 아직 미달이다.** 품질·정확도의 실패를 테스트 통과 개수로 상쇄하지 않는다.

## 실제 수정과 검증

- 원본 비트맵 장식을 실제 표 배경으로 저장하고, 앞쪽 셀의 불투명 채우기가 이를 가리지 않도록 수정했다. 이전 파일은 리소스가 있어도 실제 렌더에서 배경이 사라졌다. 본문·수식을 이미지에 합성하지 않으며 원본 이미지 조각과 픽셀 출처를 독립 대조한다.
- 큰 보기 상자 안쪽의 작은 배경 틀과 표 주변 장식도 보존한다. 국어의 원본 이미지 조각 누락 11건과 출처 대조 실패 2건을 해결했다.
- 표 오른쪽 점선과 ①~⑤를 실제 행에 속한 테두리 없는 셀로 복원한다. 세로 병합된 행도 원본 셀 범위와 연결한다. 국어 13번에서 번호와 배경이 표 아래로 중복 생성되던 오류를 수정했다.
- 세로 병합 셀의 실제 문단 높이로 행 높이를 계산한다. 병합 표의 추정 높이를 중복 계산해 뒤 문항을 다른 단으로 밀던 오류를 줄였다. 병합 셀 편집도 저장할 때 다시 조판한다.
- 국어 13번 병합 셀의 문단에 155자를 추가하고 저장·재저장했다. 셀 주소·병합·폭, 문항 글상자와 표시 범위를 유지했다. 국어·수학·영어의 대표 본문 문단 각 1개도 같은 편집 검사를 통과했다. 줄마다 별도 문단이나 글상자를 만드는 방식은 사용하지 않는다.
- 실제 렌더러가 원형 도형으로 그리는 가운데점·점선을 텍스트 검사에서 읽도록 보강했다. 관측된 원형의 크기·간격·기준선·색·클립만 사용한다. 삭제·숨김·화면 밖 이동·흰색·정의 영역에만 존재하는 변조는 실패한다. 이전 국어 10조각 미일치는 이 표시 방식의 오검출이었다.
- 수식의 소문자 `times` 등 단일 연산자를 여러 알파벳 폭으로 계산하던 오류를 수정했다. 배치 점수의 산식·합격선·시각 점수에 의한 총점 상한은 바꾸지 않았다.
