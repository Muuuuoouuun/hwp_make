# PDF → 편집 가능한 한글: 문단 주변 그림과 원본 그림 좌표 재평가

2026-09-21. [문단 띄어쓰기 개선](native-word-boundary-progress.md) 이후 같은 국어·수학·영어 36쪽을 다시 변환했다. **엄격 배치 평균은 67.65 → 68.64로, 목표 93점에 미달한다.** 한컴 애플리케이션에서 직접 열기·편집·재저장은 아직 검증하지 못했다.

## 수정한 기능과 확인한 범위

**하나의 문단으로 그림 주변에 흐르는 본문.** 원본에서는 그림 옆에서 시작해 그림 아래로 이어지는 문단을, 이전 출력은 그림과 본문을 위아래로 분리하거나 같은 폭으로 조판했다. 이제 원본의 본문·그림 위치가 이를 입증하는 경우 실제 한글의 문단 고정 그림과 사각형 둘러싸기 속성을 쓴다. 본문은 하나의 `hp:p`이며 줄별 글상자·강제 줄바꿈을 추가하지 않는다. 왼쪽 그림 아래로 본문이 돌아오면서 시작 위치가 달라지는 경우도 연속 문단으로 유지한다. 문항의 글상자 소속과 공통 지문의 별도 소속은 유지한다.

**원본 줄바꿈과 편집 후 재조판.** 실제 문단 전체의 글자가 원본 줄들과 대응할 때만 원본 줄 캐시를 적용한다. UTF-16 위치를 계산하므로 보조 평면 문자 뒤의 줄 시작도 맞는다. 텍스트 불일치, 폭 초과, 다른 문단으로 판단되는 큰 수직 간격은 적용하지 않는다. 텍스트를 수정하면 기존 캐시를 폐기하고 그림 위치와 여백에 따라 줄 폭을 다시 계산한다. 문항 글상자의 높이와 이후 문단의 페이지 배치도 갱신한다. 원본 들여쓰기와 모든 문단 스타일이 편집 후에도 완전히 같다는 뜻은 아니다.

**그림 자체의 잘림 정보.** 이전 생성기는 그림의 원본 좌표에도 표시 크기를 넣었다. 실제 원본 픽셀 크기와 표시 크기가 다른 15개 그림(국어 7, 수학 3, 영어 5)이 새 좌표 검사 및 SVG 전체 표시 검사에 실패했다. 이제 원본 그림 좌표·자르기 범위를 실제 비트맵 크기에 맞추고, 표시 크기와 확대 비율을 따로 기록한다. 내장 그림 바이트는 그대로 유지한다. 새 출력의 15개 그림은 모두 전체 표시 검사를 통과했다. 이는 이전 PNG에서 그림 15개가 아예 없었다는 뜻이 아니라, PNG 표시만으로 발견하지 못한 원본 좌표·잘림 문제다.

**검증 강화.** 원본 출처 검사에 내장 그림의 실제 픽셀 크기와 자르기 범위 대조를 추가했다. 실제 렌더 검사도 배경뿐 아니라 모든 네이티브 그림을 대상으로 한다. 문단 고정 그림은 본문과 같은 문단에 붙어 있고, 단 안에 있으며, 각 줄의 영역과 겹치지 않는 경우에만 허용한다. 임의의 비인라인 그림을 일괄 허용하지 않는다. 그림을 글 위로 옮기거나, 문단에서 떼어 놓거나, 단 밖으로 밀거나, 일부만 자르는 변조는 거부한다.

그림의 라벨은 기존 그림 픽셀에 보존되며 별도 편집 가능한 도형·글자로 바꾼 것은 아니다. 본문 이미지 덮개, 별도 편집용 동반 파일, 점수 산식 변경은 도입하지 않았다.

가중 배치 평균 68.64는 5분야 종합 점수가 아니다. 목표 93점과 기존 실물 회귀의 평균 97·최저 95·전경 겹침 97 기준 모두 미달이다. 영어 점수는 이번 변경으로 개선되지 않았다.

실물 국어의 그림 옆 문단에 148자를 넣은 결과는 17쪽으로 늘었다. 텍스트를 잘라 원래 16쪽에 가둔 결과가 아니다. 문단 전체와 그림이 같은 페이지에 남고 그림과 글자가 겹치지 않으며, 그림 바이트가 유지되는 것을 확인했다. 두 번째 저장의 섹션 XML도 동일하다. 편집 후 5쪽 PNG를 별도로 확인했다.

새 합성 회귀는 왼쪽/오른쪽 그림 × 문항 글상자/공통 지문 네 경우의 실제 PDF를 변환한다. 각각 하나의 문단, 완전한 원본 그림, 148자 추가 후 재조판·재저장, 실제 글자와 그림의 비겹침을 검사한다. 잘못된 그림 위치·잘림 변조를 거부한다. 별도 줄 캐시 회귀는 UTF-16 위치와 잘못된 원본 대응을 검사한다. 이 결과를 모든 문단·과목의 편집 호환성으로 일반화하지 않는다.
