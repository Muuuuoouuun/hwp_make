# D5 Codex — 최종 감사

## 역할
교차 평가(D4) 지적을 반영한 뒤의 최종 변경분을 감사한다. 새 취향 제안이 아니라 "배포하면 틀린 결과가 나는 곳"만 찾는다.

**읽기 전용 예외(아래 자동 첨부 규칙의 '셸 명령 금지'보다 우선한다):** 저장소를 읽는 명령은 허용한다 — 파일 읽기 도구, `rg`, `cat`, `sed -n`, `wc`, `git log`, `git show`, `git diff`. 금지: python 등 프로그램 실행, 파일 생성·수정, git 쓰기, 네트워크. 근거는 `파일:줄`.

## 대상
- 저장소: `<repo>`
- 최종 변경분: `git diff 50cd57c d6bfcfc -- app scripts/verify_recognition_content.py`
- D4 반영분만: `git diff eefba30 d6bfcfc`
- D4에서 네가 낸 지적 원문: `tmp\buster-2026-11-25\본부\원본출력\D4_codex_correctness_audit.md`

## D4 지적에 대한 본부 처리(이것이 맞게 구현됐는지 확인)
| D4 지적 | 본부 처리 |
|---|---|
| 1. 연결할 문항이 없는 지문의 본문 소실 | `pipeline.py` 미연결 지문 루프: 같은 쪽의 앞 문항(`owner`)에 글과 좌표를 되돌린다 |
| 2. 중앙 세로선이 있는 1단 시험지 | `pdf_segment.py` 단 판정: 영어 밖에서는 본문 줄이 가운데(±5%)를 가로지르지 않을 때만 세로선 단독 증거로 인정 |
| 3. 문항 없는 중간 쪽에서 지문 연결 끊김 | **보류**(코퍼스에 사례 없음) |
| 4. 13% 밴드 안의 첫 문항을 지나침 | `_page_leading_lines`: 번호 줄·범위 머리 확인을 모든 줄에 먼저 적용. 수집 경계는 실측(머리글 8~10.5%, 본문 11.8%~)에 따라 11% |
| 5. 번호 재시작 뒤 다음 유형으로 지문이 넘어감 | 지문 연결 루프에서 번호가 같거나 줄면 중단 |
| 6. 공통 자료의 그림이 앞 문항에 붙음 | **보류** |
| 7. 한 경로로 그린 표 | `_extract_figures`: 여러 요소로 된 경로의 선분(`l`)을 그림 판정용 목록에 추가 |
| 8. 8% 밖 인쇄일 | `_PRINT_TIMESTAMP_RE`: 줄 전체가 날짜·시각뿐이면 어디서든 인쇄일. 느슨한 판정(날짜로 시작, 오전·오후+숫자)은 여백에서만 |
| 9. 전각 대괄호 | 인식 정규식 두 곳에 `［］` 추가(`exam_numbering`은 그대로) |
| 10. 빠른 검수의 미측정을 실패로 기록 | `main.py`: fast면 `meets_objective_score_target`·`meets_paging_target`을 None으로 |

D4 뒤에 추가로 넣은 것:
- `pipeline._source_literal_english_pages(pages)`: PDF를 다시 열지 않고 세그멘터가 넣은 `top_quarter_lines`로 영어 판정(96책자에서 수정 전과 결과 동일함을 본부가 확인).
- `importers._choice_line_body`: 원문자 선지(①~)가 있는 문항에서 `a.` `b.` 같은 글자 라벨 줄은 선지로 보지 않는다(제2외국어 `<보기>` 항목이 선지로 들어가 선지가 8~9개가 되던 문제).
- `importers.layout_payload`: 지문 줄 좌표는 `text`·`bbox_px`·`page`만 저장.
- 지문 줄 좌표에 `page` 표시.

## 찾을 것
1. 위 처리 중 **틀리게 구현된 것**(조건 반대, 경계값, 변수 범위, None).
2. 반영이 만든 **새 회귀**. 특히: `_looks_like_date_header`의 다른 호출자(`_shared_passage_regions`의 머리글 필터)가 새 시그니처에서 같은 동작인지, `_choice_line_body` 변경이 HWP·DOCX·텍스트 가져오기의 기존 문항(A~E 선지 + 원문자 혼재)에 미치는 영향, `owner.line_geometries.extend`가 공유 리스트를 변형하는지, 경로 선분 추가로 테두리만 있는 상자가 그림으로 바뀌는 경우.
3. 새 회귀 검사(`scripts/verify_recognition_content.py`, 34항목)가 놓친 치명적 경우 최대 3개.

## 출력
맨 위에 최종 점수(100점)와 "배포 가능/보류" 한 줄 판단. 지적은 치명 → 중요 → 사소, 각각 위치(`파일:줄`) · 원문 인용 · 깨지는 입력 · 고친 코드. 지적이 없으면 없다고 쓴다. 확인 못 한 것은 '미확인'. 분량은 지적 0~8건.
