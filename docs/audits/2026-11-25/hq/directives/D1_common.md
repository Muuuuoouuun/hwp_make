# D1 공통 — 조사 단계

이 단계는 조사만 한다. 코드를 고치지 않는다. 결과는 본부가 코드 원문과 대조해 수용·기각한다.

**읽기 전용 예외(아래 자동 첨부 규칙의 '셸 명령 금지'보다 우선한다):** 이 과제는 코드 감사이므로 저장소를 읽는 명령은 허용한다 — 파일 읽기 도구, `rg`, `cat`, `sed -n`, `wc`, `git log`, `git show`, `git diff`. 금지: python 등 프로그램 실행, 파일 생성·수정, git 쓰기, 네트워크.

저장소 밖 웹 조사는 필요 없다. 근거는 URL 대신 `파일:줄`로 단다.

분량: 제안 8~15건. 줄 번호는 실제로 읽은 것만 적는다.
