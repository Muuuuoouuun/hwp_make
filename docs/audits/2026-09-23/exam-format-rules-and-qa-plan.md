# 수능·모의평가 문제지 서식 근거와 보강 기획

조사일: 2026-09-23. 이 문서는 **공개된 공식 운영 기준**, **공개 문제지에서 관찰할 수 있는 모양**, **프로젝트의 구현값**을 구분한다. 모의평가는 평가원 6·9월 모의평가, 수능은 본시험이며 교육청 전국연합학력평가는 별도 계열로 취급한다.

## 구현 순서

1. **근거 레지스트리**: 시험별 `기관/시험종류/학년도/월/영역/선택과목/문형/면수/출처 URL/확인일`을 저장한다. `official`, `observed_pdf`, `measured_hwp`, `heuristic`을 분리한다. 근거 없는 폰트·치수를 공식 규정으로 노출하지 않는다.
2. **프로필 분리**: 인쇄 원본 모사, 공개 PDF 모사, 편집용 HWPX, 학교 시험지를 각각 이름 있는 프로필로 둔다. 현재 A4와 HY신명조 값은 편집용 기본값에 남기되 출처와 허용 범위를 표시한다.
3. **사전 검수**: 표제·문형·교시·영역·선택과목·쪽수·문항 순서 및 해설 소속을 출력 전 비교한다. 충돌은 자동 추정으로 덮어쓰지 않고 수정 가능한 검수 항목으로 제시한다.
4. **렌더·인쇄 검수**: 원본과 결과의 쪽별 위치, 글꼴 대체, 겹침/잘림, 그래프 라벨, 수식·선지 기준선을 측정한다. 공개 PDF와 실제 인쇄물의 차이는 별도 기록한다.
5. **편집 검수**: HWPX 열기·본문/수식/표/미주 수정·저장·재열기·한컴 PDF 출력까지 실행한다. 자동 검사가 통과해도 GUI 미실행은 미검증으로 남긴다.

문항의 내용·정답 검토와 조판·인쇄 교정은 별도 통과 단계로 둔다. 평가원의 [『대학수학능력시험 30년사』 공개 재게시본](https://orbi.kr/download/united/73654863/1)도 출제 문항의 반복 검토와 인쇄 교정을 각각 기술한다. 이 프로젝트의 자동 검사는 문항 내용의 학문적 타당성까지 판정하지 않는다.

이 문서는 조사·기획 결과이며 이번 작업에서 템플릿이나 변환 엔진 동작을 변경하지 않았다.
