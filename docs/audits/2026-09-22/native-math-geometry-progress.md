# PDF → 편집 가능한 한글: 수식·문단 간격과 도표 오인 수정

2026-09-22 KST. **같은 국어·수학·영어 36쪽의 엄격 배치 평균은 69.09 → 76.00이다. 목표 93점에 미달하며 완성본이 아니다.** 최종 출력은 원본과 같은 16·12·8쪽이다. 전체 회귀는 **87 PASS / 11 SKIP / 2 FAIL**이며, 별도 실측·시각 검사에도 미해결 실패가 있다.

## 이번 변경

- 여러 PDF 글꼴 조각에 걸친 수식의 전체 내용이 네이티브 수식과 일치할 때 실측 폭을 사용한다. 공백·미완성 수식의 변환값이 없을 때 발생하던 예외도 처리했다. 인접한 다른 본문, 큰 간격, 다른 연산자를 끼워 맞추지 않는다.
- 수식과 본문이 섞인 **하나의 문단**에 원본 줄 높이와 기준선을 적용한다. 수식 제어 문자의 8단위·일반 문자의 UTF-16 위치를 구분한다. 서로 다른 수식의 괄호를 지워 같게 취급하거나, 한 수식을 줄 중간에서 나누는 근거는 거부한다. 줄별 글상자와 강제 줄바꿈을 추가하지 않는다.
- 지문·선택지 등 의미 문단 사이의 원본 여백을 실제 문단 뒤 간격으로 저장한다. 글상자 생성·수정 후 높이 계산과 별도 경계 검사에 이 여백을 포함한다. 내용이 늘어나면 같은 문단과 문항 글상자를 유지하며 높이를 갱신한다.
- 막대그래프의 가로선을 표로 오인하던 문제를 수정했다. 가로선만 있고 빈 띠가 반복되는 영역에는 이어진 세로선 근거가 필요하다. 숫자만 있는 무세로선 후보는 실제 열의 왼쪽·가운데·오른쪽 정렬 근거도 확인한다. 막대 안의 숫자를 별도 표로 중복 출력하던 사례가 제거됐다. 빈 행이 있는 실제 테두리 표와 자릿수가 다른 오른쪽 정렬 숫자 표는 회귀에서 보존된다.

중간 버전은 영어가 8 → 9쪽으로 늘었고 배치 평균도 64.37로 떨어졌다. 실패 자료는 `data/verification/20260922_goal_native_math_geometry/`에 보존했다. 도표 오인 수정 후 별도 폴더에서 세 과목과 전체 회귀를 다시 실행했으며 아래 표는 그 최종 결과다.

## 엄격 검사에서 남은 실패

**전체 회귀의 두 실패:** `verify_external_exam_detail_quality.py`의 평균 97·최저 95·전경 겹침 97% 기준을 충족하지 못한다. `verify_native_choice_tabs.py`도 선택지 위치 오차 **7.89px > 6px**로 실패한다. 생략하거나 기준을 낮추지 않았다.

**수학 1쪽 1번 직접 실측:** 원본 PDF 수식 폭은 **72.5635pt**다. 출력 폭은 **52.9651 → 72.5604pt**로 개선됐다. 지문과 첫 선택지의 기준선 간격 오차는 **8.778 → 0.115px**로 줄었지만, 별도 **0.1px** 검사에는 여전히 실패한다. 첫 문항 시작 위치는 원본보다 약 **20.56px** 위에 있으며, 직전 약 10.37px보다 절대 위치 오차가 커졌다. 부풀린 줄 높이가 줄어든 뒤 드러난 전체 배치 오류를 개선으로 취급하지 않는다. 이 별도 검사 실패는 위의 100개 회귀 집계에 포함되지 않는다.

**국어 16쪽 시각 검토:** 시의 원래 행·연 간격이 보존되지 않았고, 마지막 선택지·확인사항 영역에 텍스트가 겹쳐 보인다. 새로 연 문서에서 렌더한 PNG도 같은 픽셀 문제를 보였다. XML의 확인사항 텍스트는 올바르고 SVG의 해당 문구와 보기 문구도 각각 한 번 존재한다. 따라서 원문 데이터 삭제나 중복을 확정하지 않는다. SVG 텍스트 존재 검사로 PNG 표시·겹침까지 보증할 수 없다는 검증 한계다. 네이티브 배치와 렌더러 동작을 더 분리해 조사해야 한다.

**HWPX 가져오기:** [연구 인계](../2026-09-21/exam_hwp_session_handoff.md)를 받아 현재 `import_hwpx`를 별도 DB에서 다시 실행했다. 공개 영어·수학·국어·지구과학은 미주가 각각 45·46·45·20개인데 모두 **1문항으로 생성**, 정답·해설 필드는 0개였다. 긴 미주 텍스트 일부도 본문으로 들어갔다. 이번 수정에서 해결하지 않았다. 미주의 `instId`가 반복될 수 있으므로 고유 키로 가정해서도 안 된다. 미주 소속 수식·그림을 함께 보존하는 가져오기 수정이 별도 P0다.

한컴 GUI는 연구 세션에서 Windows 잠금 화면 때문에 검증하지 못했다. 사용자가 직접 잠금을 해제한 뒤 현재 창을 다시 확인하고 실험용 사본으로 열기·편집·재저장을 수행해야 한다. 구조 검사와 rhwp 결과를 한컴 편집 통과로 바꾸어 쓰지 않는다.
