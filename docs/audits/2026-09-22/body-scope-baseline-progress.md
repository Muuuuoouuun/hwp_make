## 본문과 머리말을 분리한 대조

기존 비교기는 문단 사이에 저장된 `header`·`footer` 제어의 텍스트를 본문에 이어 붙였다. 실제로 존재하는 국어 문구 `물음에 답하시오`를 `물음에국어영역고1고1국어영역답하시오`로 읽어 27자를 불일치로 보고했다. 반대로 본문에서 지운 문장이 머리말에 있으면 일부 대조 경로가 이를 본문 보존으로 오인할 수 있었다.

이제 본문·문항별 대조와 생성 통계의 텍스트 읽기에서 머리말·꼬리말의 하위 내용을 제외한다. 같은 본문 문단의 앞뒤 run은 계속 이어 읽으며, 실제 표 셀·그림 옆 문단·텍스트 제어 뒤의 tail과 수식은 유지한다. 머리말의 존재·자동 번호·실제 표시는 별도 원본 대조에서 계속 검사한다.

- 본문 중간에 머리말 또는 꼬리말 제어를 넣어도 원문 대응과 문항별 대조를 유지한다.
- 본문을 지우고 같은 문장을 머리말 또는 꼬리말로 옮기면 **전체 본문 및 해당 문항 대조 모두 실패**한다.
- 생성 통계를 보존율 100%로 위조해도 `structured`·`coordinate` 각각 2개, 총 **4개 API 변조 검사가 422**를 반환한다. 거부한 결과 파일도 정리된다.
- 세 과목의 실제 본문 텍스트와 수식 스크립트는 이전 변환본과 같다. 누락된 27자를 새로 추가한 것이 아니라 잘못된 비교를 수정했다.

현재 텍스트층 대응은 국어 **27,028/27,028**, 수학 **1,609/1,609**, 영어 **23,681/23,681**이다. 이 값은 원문 조각의 대응이다. 그림 속 글자, 중복 표시, 모든 의미·읽기 순서의 정확도를 보증하지 않는다. 아래 그래프 표기의 중복은 이 비율과 별개의 실제 실패다.

## 첫 줄 수식과 본문 기준선

같은 기준선에 있는 일반 글자와 큰 수식은 필요한 문단 위쪽 공간이 다르다. 뒤쪽 구역의 시작 위치를 여러 단 시작점의 중앙값으로 정하면 큰 수식에 필요한 위쪽 공간을 확보하지 못했다. 이후 간격은 음수가 될 수 없어 문항 전체가 아래로 밀렸다. 이제 측정된 시작점 중 가장 위쪽을 구역의 시작으로 쓰고, 나머지 간격은 일반 문단 여백으로 유지한다.

또한 본문 기준선을 수식의 괄호·첨자·변수 스팬까지 섞어 계산하던 부분을 수정했다. 해당 문단의 실제 본문 글꼴 스팬을 우선 사용하며, 이 스팬이 없을 때만 다른 측정값을 사용한다. 줄별 글상자, 임의 페이지 좌표, 본문 이미지 덮개를 추가하지 않았다.

수학 2~12쪽 양쪽 단의 첫 문항 번호 **22개**를 원본 PDF와 출력 SVG에서 직접 대조했다. 최대 **세로 기준선 오차는 3.0169px → 0.003541px**로 0.1px 기준을 통과한다. **가로 위치의 통과를 뜻하지 않는다.** 수학 9쪽 22번 시작점의 가로 오차 +0.4449px는 같은 0.1px 기준에 여전히 실패한다.

수학 4쪽 그림의 세로 오차는 +2.8783 → **−0.0017px**로 수정됐다. 7쪽은 +0.0068px로 유지된다. 11쪽은 +15.6557 → **+12.7757px**로 줄었지만 실패다. 그림 앞 문단에 197자를 추가하는 편집에서는 같은 문단·수식·그림과 12쪽을 유지하며 그림이 아래로 이동한다.

## API·패키지·재현 근거

실제 국어 `structured`와 수학 `coordinate` 요청 모두 변환·다운로드 HTTP 200을 확인했다. 다운로드한 파일은 각각 531,980·92,383바이트이며 원문 편집성 검사와 패키지 검증을 통과한다. 실제 API 종합 지표는 국어 **86.55**, 수학 **83.50**으로 목표 미달이다. 수학 88.23은 별도 배치 지표이며, API의 구조 점수와 결합된 종합 지표와 같지 않다.

정상 출력·편집·재저장·실제 다운로드 패키지 **33개**는 오류·경고 0이다. 의도적인 변조 파일은 정상 패키지 수에 포함하지 않는다. Python 소스 8개가 이전 평가본과 달라졌으며, 36쪽 평가에 사용한 소스를 고정하고 후속 검사 뒤 파일 추가·삭제까지 비교한 차이는 **0개**다. 렌더러는 기존 `rhwp-python 0.7.0+nativecell1`을 유지하며 실제 설치 바이너리와 wheel 해시도 일치한다.
