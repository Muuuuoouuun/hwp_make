# PDF → 편집 가능한 한글: 첫 쪽 머리말·구역 배치 수정

2026-09-22 KST. **국어·수학·영어 36쪽의 엄격 배치 평균은 76.00 → 77.52다. 목표 93점에 미달하며 완성본이 아니다.** 최종 출력은 원본과 같은 16·12·8쪽이다. 문항 글상자 내부의 문단 연결과 실제 편집·재저장을 함께 검사했다.

## 수정 내용과 검증 기준

- 제목·영역명·교시·첫 쪽 번호의 원본 글꼴 크기, 시작점, 기준선, 한글 자폭·자간을 읽는다. 제목과 같은 PDF 줄에 섞인 쪽 번호를 제목 크기와 영역에서 제외한다.
- 머리말은 편집 가능한 표와 문단을 담은 **실제 구역 머리말**로 구성한다. 제목과 본문을 한 단의 임의 고정 높이로 묶지 않고 원본에서 측정한 본문 시작 위치를 적용한다. 첫 쪽의 페이지 번호도 실제 텍스트다.
- 뒤쪽 구역은 자체 위 여백으로 쪽 나눔을 계산한다. 첫 쪽의 큰 머리말 때문에 뒤쪽 본문의 정상 문단 간격이 제거되던 회귀를 수정했다. 다음 구역의 빈 머리말을 명시해 첫 쪽 제목이 상속되어 반복되는 문제도 막았다. 원본에서 확인되는 뒤쪽 영역명은 기존의 반복 머리말로 유지한다.
- 새 머리말 스타일과 본문 스타일의 ID가 충돌하지 않도록 갱신하며, 굵기가 다른 글자 스타일을 캐시에서 구분한다.
- 머리말 검사의 기존 ‘템플릿 전체 높이 유지’ 조건은 잘못된 고정 위치를 보존하는 조건이었다. 이를 **PDF의 시작점·기준선 0.1px 이내, 실제 본문 시작점, 다음 쪽 전체 글자 좌표 불변, 문단 편집·재저장** 검사로 교체했다. 배치 점수 산식, 외부 시험지 품질 기준, 선택지 6px 기준, 수학의 별도 0.1px 기준은 낮추지 않았다.

개발 중 첫 구현은 국어 17쪽·영어 9쪽으로 늘어 불합격했다. 실패 결과와 당시 소스는 `data/verification/20260922_goal_native_masthead_flow/`에 보존했다. 구역 수정 후 별도 최종 폴더에서 다시 변환하고 검사했다.

## 실측과 남은 실패

**전체 회귀의 두 실패:** `verify_external_exam_detail_quality.py`의 평균 97·최저 95·전경 겹침 97% 기준을 충족하지 못했다. `verify_native_choice_tabs.py`도 선택지 위치 오차 **7.89px > 6px**로 실패했다. 두 기준을 유지했으며 실패 종료를 생략으로 처리하지 않았다.

**머리말 12개 항목:** 세 과목의 제목·영역명·교시·쪽 번호의 시작점과 기준선 오차는 최대 **0.0152px**였다. 0.1px 검사를 통과했다. 이는 각 항목의 시작점·기준선 검사이며 모든 글자 폭·굵기·테두리가 일치한다는 의미가 아니다. 실제 수학 첫 쪽 비교에서는 영역명 굵기, 교시의 둥근 테두리, ‘5지선다형’ 상자 폭, 구분선과 하단 쪽 번호 등의 차이가 남았다.

세 과목 영역명 글꼴을 추가로 조사한 결과 PDF의 `T4`/`T5`는 Type3였으며, 현재 추출 API는 해당 항목의 글꼴 파일을 반환하지 않았다. 이 이름만으로 원래 설치 글꼴을 특정할 수 없다. 해당 실물 목록은 `heading_font_inventory.json`에 보존했다.

**수학 1쪽 1번:** 시작 기준선의 절대 오차는 약 **20.56 → 0.228px**로 감소했다. 지문과 첫 선택지 사이 간격 오차는 **0.115px**로 남았다. 두 항목 모두 별도 **0.1px** 기준에는 실패한다. 실패 종료와 수치를 그대로 보존했으며 전체 회귀 집계와 별도로 공개한다.

**국어 16쪽 시각 검사:** 최종 PNG에서도 시의 행·연 간격 손실과 마지막 선택지·확인사항의 겹침이 남았다. 해당 쪽은 직전 출력과 픽셀이 같다. 이전 조사에서 XML의 확인사항 원문은 올바르고 SVG 문구도 각각 한 번 존재했다. 텍스트 존재 검사를 겹침·외관 통과로 바꾸지 않는다.

**HWPX 가져오기:** [연구 인계](../2026-09-21/exam_hwp_session_handoff.md)와 [직전 재현](native-math-geometry-progress.md)의 공개 4종 미주 가져오기 실패는 이번 수정 범위 밖이다. 영어·수학·국어·지구과학의 미주 45·46·45·20개가 각각 1문항으로 생성되고 정답·해설 필드가 비어 있었다. 원본 번호와 미주 소속 텍스트·수식·그림을 함께 보존하는 수정이 필요하다.

한컴 GUI는 연구 세션에서 Windows 잠금 화면으로 검증하지 못했다. 사용자가 직접 잠금을 해제한 뒤 실험용 사본으로 열기·문단 편집·재저장해야 한다. 구조 검사와 rhwp 결과만으로 한컴 호환성 완료를 선언하지 않는다.
