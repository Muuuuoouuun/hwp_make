# 변환 보존·실패 복구 개선 결과

2026-09-05 감사 후 승인된 구현이다. [최초 감사](conversion-review.md)의 재현 결과는 수정 전 증거로 유지한다. 사용자 기본 DB에 새 테스트 데이터를 넣거나 기존 해시를 일괄 재작성하지 않았다. 모든 실행 검증은 새 TEMP 데이터 경로에서 수행했다.

## 적용한 변경

| 감사 항목 | 구현 | 검증 |
| --- | --- | --- |
| C1 · x/X 중복 오판 | 새 콘텐츠 해시는 대소문자를 보존하고 `v2:`를 표시. 이전 소문자 해시는 후보 검색 후 실제 저장 콘텐츠를 다시 비교하므로 기존 행 재작성 없이 이전 자료도 멱등 재가져오기 가능. | 동일 CSV의 x/X 둘 다 생성, 이전 해시의 정확 재가져오기·existing ID 재사용, 이전 해시 행 유지, 출처 분리, 이미지/표가 있는 이전 해시 호환 및 표 대소문자 보존 통과. |

새 관문은 `python scripts/verify_conversion_integrity.py`이며 최종 실행 **36 PASS / CONVERSION_INTEGRITY_OK**다. 기존 `verify_api_hardening.py`, `verify_pdf_layout_export_api.py`도 PASS다. 컴파일과 `git diff --check`를 통과했다. 전체 `run_all_verify.py`는 고정 로컬 산출물/개인 샘플 의존성이 있어 이번 결과로 전체 그린을 주장하지 않는다.

## 남겨 둔 한계

- C6의 좌표 그림을 inline 전용 검사에 넣는 판정 충돌은 무조건 PASS로 바꾸지 않았다. 기존 수식 높이 검사 결과는 실패 종류를 확인해야 하며, 순수 reflow와 좌표 overlay에 대한 별도 편집 안전성 검증이 필요하다.
- 첫 유형 자동 탐지는 사용자가 `first`를 명시한 경우의 편의 기능이다. 탐지 실패 시 선택 범위를 전부 보존하고 이유를 안내한다. 내용이 일부 다른 합본을 합치거나 삭제하도록 기본 동작을 되돌리지 않는다.
- 단일 파일 요청의 서버 처리 중단 기능은 추가하지 않았다. UI의 응답 대기 취소와 서버 변환/DB 처리 취소는 여전히 구분해야 한다.
- 실제 한글 GUI/Word 편집 후 인쇄 일치, OCR 설치 지원선 및 새로운 시험지 전체에 대한 품질 보증은 이 변경의 검증 범위가 아니다.

실물 40쪽 재변환의 후속 측정은 [real-math-improved.json](real-math-improved.json)에 별도로 기록한다. 합성 관문과 실물 측정은 구분해서 해석한다.
