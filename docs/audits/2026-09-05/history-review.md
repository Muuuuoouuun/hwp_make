### B. 시각 overlay 아래의 편집 결과가 합격 기준에 덜 반영됨

보존된 국어 보고서는 text visual overlay 면적비0.534, 편집 텍스트 coverage1.0을 동시에 기록한다. 두 사실은 양립한다. 텍스트가 존재하면서 이미지 레이어가 인쇄 외형을 보존할 수 있다. `app/pdf_layout_fidelity.py:538–549`는 합성 전 editable layer 지표를 명시적으로 informational-only, pass/fail 비영향이라고 설명한다.

이 구조가 곧 결함이라는 뜻은 아니다. 다만 “텍스트 있음+출력 원형 유지”와 “사용자가 고친 텍스트가 실제 보이는 편집형 문서”는 다르므로 직접 편집 검증이 필요하다. 국어 문장1개, 수학 분수1개, 표 셀1개를 바꾸고 재열기/재렌더해서 변경 가시성, 기존 overlay 잔상, 선택 가능성, 읽기 순서, 저장 후 유지 여부를 확인해야 한다.

### C. PASS/SKIP 분모와 파일 출처가 고정되지 않음

권장 acceptance: 필수/선택 fixture manifest, 파일 hash, commit, 실행시각, writer/mode, AI/OCR/폰트 환경, 원본쪽수/비교쪽수, 내부 case SKIP 목록을 함께 저장. “전체 통과”와 “가용 표본 통과”를 구분. 문제 출력 폴더를 우연히 청소하거나 다른 임시파일을 생성해 gate 분모가 변하지 않도록 고정 fixture에서 생성→검사를 연속 수행.
