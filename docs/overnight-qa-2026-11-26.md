- 웹: 기본 홈에는 무료 변환만 보인다. 일괄 체험은 로컬 주소의 `?internal-preview=1`에서만 보이는 UI 미리보기다. 이는 인증이나 유료 이용권 구현이 아니다. 사용량(3회/실패 미차감), 원본 보존 및 결과 확인 동선은 기존 정책을 유지했다.

프리미엄 내부 기획 72/100 (QA 판단): 번호·순서 엔진 25/30, 편집 방향·통제 20/25, 상태·복구 14/20, 배포 안전·서비스 준비 13/25. 사용성/운영 준비가 남았으므로 배포하지 않는다.
1. ‘시험지 편집’에서만 유료 후보 UX를 설명한다. 화면은 왼쪽 문항 목록, 중심 시험지, 오른쪽 번호/출력 조건. 모바일은 문항→미리보기→설정의 탭으로 분리한다.
2. 번호 옵션은 ‘원본 유지 / 1부터 다시 / 시작 번호 지정’으로 표시한다. 이동 버튼·키보드 접근과 문항 12→21 미리보기, 해설/정답 동기화를 한 화면에서 확인한다. 공통 지문과 본문 속 수동 참조 번호를 재번호에 섞지 않는다.
3. 내보내기 전 ‘변경 7개’, 빠진 정답/중복 번호, 공유 지문 충돌을 알려준다. 기본판에서 저장한 원본은 유지한다. 새로고침/동시 편집/되돌리기와 초안 수명을 합성 데이터로 먼저 검증한다.
4. 상업 배포 전 서버에서 만료·권한·사용량을 검사하고 로컬 미리보기 플래그와 분리한다. 청구 연동은 이번 결과에 없다.
