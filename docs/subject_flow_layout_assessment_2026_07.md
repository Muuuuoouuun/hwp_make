# 전과목 PDF flow 레이아웃 평가와 개선

측정일: 2026-07-17

## 범위와 판정

- 입력: 2026년 6월 고1 국어·영어·수학·통합사회·통합과학·한국사 문제 PDF 6부, 총 52쪽
- 출력: `write_pdf_flow_hwpx()`의 편집 가능한 2단 HWPX
- 기준: 원본 본문 레일, 반복 머리말, 문항 흐름, 표·자료 박스, 수식 가독성, overflow와 단 침범
- 원칙: 전체 페이지 이미지는 사용하지 않고 텍스트를 우선한다. 복잡 표와 2차원 수식은 필요한 작은 영역만 이미지로 보존한다.

## 발견한 템플릿 편법과 개선

| 항목 | 기존 상태 | 개선 결과 | 현재 판정 |
| --- | --- | --- | --- |
| 좌우 여백 | 7mm 고정값으로 원본보다 본문 폭이 넓음 | PDF 텍스트 레일의 중앙값에서 좌 30.55~30.59mm, 우 29.04~30.34mm 추정 | 검증됨 |
| 본문 높이 | 페이지 높이의 62% 상한 때문에 아래 문항이 잘림 | 머리말 아래부터 하단 여백까지 전체 높이 사용 | 검증됨 |
| 반복 머리말 | 첫 쪽 뒤 머리말을 삭제하고 빈 간격으로 대체 | 52쪽 모두 머리말 유지 | 검증됨 |
| 머리말 구조 | 2열 본문 셀 안에 3열 표를 중첩해 높이가 부풀어 오름 | 최상위 3열 머리말 표와 2열 본문 표를 분리 | 검증됨 |
| 숨은 여백 | 새 문서 기본 머리말·꼬리말 여백 15mm가 추가됨 | 두 값을 0으로 명시 | 검증됨 |
| 머리말 밑줄 | 긴 밑줄 문자를 텍스트로 출력 | 표 셀의 실제 아래 테두리로 변환 | 검증됨 |
| 머리말 정렬 | 쪽수·과목명·학년을 모두 왼쪽 정렬 | 왼쪽·가운데·오른쪽 정렬로 분리 | 검증됨 |
| 본문 글자 | 11.15pt 본문과 약 31pt 제목을 10pt·16pt로 강제 | 원본 크기를 7~38pt 범위에서 유지, 장평 86·자간 -5·줄간격 150% | 부분 완료 |
| 복잡 표 | 벡터 밀집 페이지에서 표 검출을 꺼 한국사 연표가 풀림 | 캐시한 지역 선분으로 표를 다시 검출해 작은 영역 이미지로 보존 | 검증됨 |
| 인라인 수식 | HyhwpEQ PUA가 사각형 또는 겹친 문자로 남음 | 유니코드와 위첨자로 복구하고 Times New Roman으로 출력 | 부분 완료 |
| 분수·근호 수식 | 여러 줄 문자 배치가 겹쳐 읽기 어려움 | 해당 수식의 작은 원본 영역만 이미지로 보존 | 검증됨 |

한국사 기준 기존 출력의 가로 사용 범위는 페이지의 약 2.4~97.6%였고 원본은 약 10.4~89.6%였다. 개선 출력은 약 10.34~89.66%로 원본 레일에 맞았다. 기존 하단 본문은 원본 높이의 약 67.2%에서 끊겼지만 개선 후에는 하단 문항까지 유지됐다.

## 최종 변환시간

문항 인식은 제외하고 레이아웃 HWPX 변환만 1회 측정했다.

| 과목 | 쪽 | 변환시간 | 머리말 | 지역 이미지 |
| --- | ---: | ---: | ---: | ---: |
| 국어 | 16 | 2.482초 | 16 | 17 |
| 영어 | 8 | 1.938초 | 8 | 9 |
| 수학 | 12 | 1.269초 | 12 | 12 |
| 통합사회 | 6 | 8.049초 | 6 | 31 |
| 통합과학 | 6 | 4.536초 | 6 | 39 |
| 한국사 | 4 | 3.413초 | 4 | 15 |
| 합계 | 52 | 21.687초 | 52 | 123 |

최초 기준 217.539초보다 90.0% 빠르고, 성능 최적화 직후 20.494초보다 5.8% 느리다. 이 증가는 반복 머리말, 원본 본문 레일, 복잡 표와 2D 수식 보존을 추가한 비용이다.

## 회귀 결과

- 6개 HWPX, 총 52쪽 재렌더 완료
- 머리말 52/52
- overflow 0, column crossing 0
- HWPX package와 구조 validator 통과
- 수학 24·26번 인라인 수식은 편집 텍스트로 복구
- 수학 25번 분수·근호는 작은 지역 이미지로 원형 보존
- 한국사 8번 연표를 포함한 자료 표 유지
- 벡터 밀집 합성 PDF 10초 성능 관문 유지

## 남은 한계

1. 분수·근호·복잡 연표의 지역 이미지는 모양은 정확하지만 내부 요소를 개별 편집할 수 없다.
2. 인라인 수식은 읽을 수 있는 선형 유니코드이며 한컴의 네이티브 2D 수식 객체는 아니다.
3. 원본의 둥근 학년 캡슐은 오른쪽 정렬 텍스트로 단순화했다.
4. 현재 판단은 2026년 6월 고1 교육청 계열 6과목에 강하다. 다른 출판사·학년·용지 비율은 별도 profile 검증이 필요하다.
